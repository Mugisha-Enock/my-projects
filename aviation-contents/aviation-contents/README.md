# Aviation Contents (frontend prototype)

Single-file prototype. Open `index.html` in a browser, or serve the folder:

    npx serve .

Demo mode only: sign-in is fake and published stories live in memory until reload.
The real-time layer is the `rt` object in index.html (swap for socket.io-client later).
Not yet built: login/register, dashboard, photo lightbox, video player, magazine reader, media upload.
