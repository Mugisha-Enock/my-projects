# Add Calculator (React)

## Run it
```bash
npm install
npm run dev
```
Then open the address shown in the terminal (usually http://localhost:5173).

## Structure
```
src/
  main.jsx                     starts React
  App.jsx                      page layout
  App.css                      all styles
  components/
    AddCalculator.jsx          state + Add / Clear logic
    NumberField.jsx            reusable label + input
```
